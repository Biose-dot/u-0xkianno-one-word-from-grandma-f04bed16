## The word

> **APATUH**

Grandma's typo for *"apa tuh?"* ("what's that?") — the two words squished into one the way she actually types them. Warm, a little baffled, and funny with no caption needed: it is her very first reaction the moment someone shows her AI. The brief explicitly counts a typo she would actually make, and this one lands because every grandchild has received exactly this text.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

Deterministic, offline, no dependencies: `main.ts` (Node 22) writes the 6-character word to `/output/entry.txt` with no trailing newline.
